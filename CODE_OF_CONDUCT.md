# Code of Conduct

Yinne adopts Contributor Covenant 2.1. We pledge a harassment-free, inclusive community. Be respectful, assume good intent, criticize ideas rather than people, and protect private/security information.

Maintainers may restrict participation for harmful behavior. Report concerns privately to conduct@yinne.dev. Before public contribution begins, maintainers must configure a monitored replacement if that address is unavailable. Reports are confidential and retaliation is prohibited.

Canonical text: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
