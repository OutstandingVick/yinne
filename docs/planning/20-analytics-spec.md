# Analytics specification

Analytics is API-defined; dashboards render returned definitions. Canonical interval is [from,to), instants UTC, grouped by requested IANA timezone (organization default). Results include timezone, currency, freshness, formula version, and filters. Never sum currencies; require currency or return partitions.

| Metric               | Formula                                                                                                  | Sources                                     | Refund/time treatment                                                                     |
| -------------------- | -------------------------------------------------------------------------------------------------------- | ------------------------------------------- | ----------------------------------------------------------------------------------------- |
| GMV                  | sum succeeded charge transaction amount                                                                  | transactions/payments                       | gross; refunds shown separately; provider occurred_at                                     |
| Net revenue          | GMV minus succeeded refunds; excludes provider fees/tax/shipping only when explicit dimensions requested | charge/refund transactions, order snapshots | refund counted at refund occurred_at; label “net processed sales,” not accounting revenue |
| Transaction count    | count succeeded charge transactions                                                                      | transactions                                | refunds excluded                                                                          |
| AOV                  | paid order gross / distinct paid orders                                                                  | orders + payment evidence                   | original paid total; refunded AOV variant separately                                      |
| Checkout conversion  | completed sessions / eligible created sessions                                                           | checkout sessions                           | cohort by created_at; exclude test/admin fixtures                                         |
| Refund rate          | succeeded refund amount / succeeded charge amount                                                        | transactions                                | same reporting-window occurrence; cohort variant named separately                         |
| MRR                  | sum normalized active recurring price amounts                                                            | subscriptions/prices                        | PLANNED; excludes one-offs; currency partition                                            |
| ARR                  | MRR x 12                                                                                                 | subscription metric                         | PLANNED                                                                                   |
| Churn                | subscriptions ended in period / active at period start                                                   | subscriptions                               | PLANNED; logo vs revenue explicitly named                                                 |
| Customer LTV         | realized net processed sales per customer, or modeled method explicitly named                            | orders/customers/refunds                    | PLANNED modeled; anonymous excluded/disclosed                                             |
| Repeat purchase rate | customers with >=2 paid orders / customers with >=1                                                      | orders/customers                            | window/cohort declared; anonymous excluded                                                |
| Revenue by product   | allocated paid order item gross minus allocated refunds                                                  | order items/transactions                    | deterministic proportional allocation                                                     |
| Revenue by location  | net processed sales for immutable order location                                                         | orders/transactions                         | no reassignment of history                                                                |
| Revenue by channel   | net processed sales by order channel snapshot                                                            | orders/transactions                         | storefront/link/API dimensions                                                            |
| Revenue growth       | (current comparable net - previous) / abs(previous)                                                      | metric series                               | null when previous zero, not infinity                                                     |
| Revenue volatility   | standard deviation / mean of complete weekly net series                                                  | metric series                               | null if mean <=0 or <8 weeks                                                              |

V1 real metrics: GMV, net processed sales, transaction count, AOV, checkout conversion, refund rate, product/location/channel revenue, growth, volatility, repeat rate where identity coverage is disclosed. Subscription metrics and modeled LTV are planned.

Use direct indexed SQL initially, with daily aggregate tables only after correctness tests and measured need. Late provider events update affected buckets and freshness watermark. Test/live and scoped permissions always filter before aggregation. Reconciliation corrections carry occurred_at and recorded_at; API can explain restatements.

Acceptance: fixtures hand-calculate exactly; DST, zero/three-decimal currency, partial refund, late event, anonymous buyer, and scoped location tests pass. UI never displays an unlabeled mixed-currency or stale metric.
